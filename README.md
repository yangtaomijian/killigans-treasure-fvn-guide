# Killigan’s Treasure 玩家攻略 / Player Guide

[中文站](https://killigans-treasure.carambi.com/) · [English site](https://killigans-treasure.carambi.com/en/)

《Killigan’s Treasure》是 **Eddio** 创作的兽人视觉小说。本项目是面向 **Public v0.57a** 的非官方中英双语玩家攻略，由 [Carambi](https://carambi.com/zh/)（[@yangtaomijian](https://github.com/yangtaomijian)）维护。

*Killigan’s Treasure* is a furry visual novel by **Eddio**. This unofficial Chinese and English player guide covers **Public v0.57a** and is maintained by [Carambi](https://carambi.com/) ([@yangtaomijian](https://github.com/yangtaomijian)).

## 从哪里开始 / Where to start

- **推进旅程：** 从[红根镇](https://killigans-treasure.carambi.com/guide/redroot.html)开始，按地点查找选择、条件与存档建议。
- **查看关系与机制：** 阅读[关系发展](https://killigans-treasure.carambi.com/reference/relationships.html)、[性格](https://killigans-treasure.carambi.com/reference/personality.html)和[战斗与 QTE](https://killigans-treasure.carambi.com/reference/combat.html)。
- **补齐收集：** 查看[回忆与画面](https://killigans-treasure.carambi.com/collectibles/memories.html)、[图鉴](https://killigans-treasure.carambi.com/collectibles/codex.html)、[装备与物品](https://killigans-treasure.carambi.com/collectibles/equipment.html)及 [Dressing Room](https://killigans-treasure.carambi.com/collectibles/dressing-room.html)。
- **遇到问题：** 查看[帮助](https://killigans-treasure.carambi.com/help.html)，或使用站内搜索查找角色、地点和条目。

- **Follow the journey:** Start in [Redroot](https://killigans-treasure.carambi.com/en/guide/redroot.html) for choices, prerequisites and save advice.
- **Understand relationships and mechanics:** Read [Relationships](https://killigans-treasure.carambi.com/en/reference/relationships.html), [Personality](https://killigans-treasure.carambi.com/en/reference/personality.html), and [Combat & QTEs](https://killigans-treasure.carambi.com/en/reference/combat.html).
- **Complete collections:** Browse [Memories / CG](https://killigans-treasure.carambi.com/en/collectibles/memories.html), [Codex](https://killigans-treasure.carambi.com/en/collectibles/codex.html), [Equipment](https://killigans-treasure.carambi.com/en/collectibles/equipment.html), and [Dressing Room](https://killigans-treasure.carambi.com/en/collectibles/dressing-room.html).
- **Find help:** Open [Help](https://killigans-treasure.carambi.com/en/help.html), or search for a character, location or entry.

## 阅读前 / Before you read

**本攻略包含剧透。** 内容从开场写到蓝叶森林 **Day 12** 晚营后的版本终点，只跟进当前公开版本；后续游戏版本的选择、条件或收集内容可能不同。

**The guide contains spoilers.** Coverage runs from the opening through the end of **Blueleaf Grove Day 12**, after the evening camp scene. It follows the public release; later game builds may change choices, conditions or collectibles.
