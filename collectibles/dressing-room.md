# Dressing Room：服装、表情与解锁

适用版本：Killigan’s Treasure Public v0.57a。**Dressing Room** 汇集人物的可选表情与服装外观，先选人物（Character），再分别调整表情（Expressions）与服装（Outfit）。物品取得、属性与穿戴限制见[装备页（Equipment）](equipment.md)；菜单与迁移问题见[帮助](../help.md#help-item-status)。

## Dressing Room 定位器 {#dressing-room-locator}

先选人物和服装部位，再对照游戏圆形区域里的编号，查看选项的取得方式。编号沿用游戏显示的写法，包括 `3_r`、`3_h`；出现跳号不代表中间还有选项需要补齐。

**编号不等于不同服装的数量。** `3_r` 对应特制参赛服（Prime Attire）的取得，`3_h` 随赛后剧情开放；本版本切换这两项不会显示对应衣物，不要把它们当成两套需要分别收集的服装外观。

这里使用部位的英文名称配合中文解释来对应游戏图标；**某部位只有一个选项时没有切换图标是正常行为**。这里列出本版本正常游玩可以开放的服装选项，尚未到达的地区或成人内容设置也会影响你的菜单。表情的开放方式见下方 [Expressions 说明](#dressing-room-expressions)。

## Dressing Room 的结构 {#先选人物再分别调表情与服装}

入口位于 **Gallery → Dressing Room**。左右箭头切换地区／团体分组，点选人物后，可以分别调整表情与服装。初始分组包括 **Treasure Crew、Redroot、Redroot Wilds、Aris、Arcane Academy、Athlima Summit、Aris (contd.)**；之后随旅程加入 **Crystal Plains** 与 **???**，Zhokhar 也会加入 Treasure Crew。各人物的表情和服装选项随各自的开放条件增加。

- **Expressions 在左侧：**展开列表选择表情，与右侧服装部位独立。
- **Outfit 在右侧：**部位图标切换服装部位，上下箭头循环该部位的可用选项。已开放的不同部位可以自由组合。
- **部位因人物而异：**主角可调上身、腰带、鞋靴、地图挂带、下装、内衣，以及解锁后可切换的武器；部分人物另有配饰、色彩或专属外观变化。成人表现还受内容设置影响。这里以中文描述图标所对应的部位；切换图标在该部位有多种可用外观时出现。

<a id="dressing-room-expressions"></a>

## Expressions {#expressions看过与可选不是一份总数}

**可选表情随正常剧情中已经出现过的表情增加。** 列表通常依据本机的观看历史，因此不同人物、不同游玩进度下数量会不同；部分人物有起始表情。主角的表情也随其剧情呈现开放。表情与装备持有、伴侣确认及服装收集是独立的内容。

补收某个表情时，可从对应场景前的普通存档重看人物呈现，再返回 Dressing Room。这里以可选表情和外观为索引，服装组合与单次画面的变体不另计收集项。

<a id="dressing-room-unlocks"></a>

## Outfit：默认、自动与可选解锁 {#outfit默认自动与可选解锁}

默认外观随人物提供；剧情外观在对应旅程节点自动加入；可选衣物通过奖励或购买开放。**已取得的外观解锁跨存档保留，当前剧情存档中的实体物品则依该存档的取得记录。** 错过的奖励与选择可以从相应窗口前的普通存档补收。

## Equipment、穿着与外观解锁 {#equipment-持有穿着与换装解锁分别查}

::: {.kt-adaptive-records}

| 状态 | 对应记录 |
|---|---|
| 物品持有 | 当前剧情存档的物品，见 **Equipment**；后期也要查看同行者的共享箱子（shared trunk）。 |
| 当前穿着 | **Equipment** 的已穿状态，决定当前属性或战斗用途。 |
| 换装解锁 | 本机持久保留的人物、部位与可选外观，与当前剧情存档的装备状态独立。 |
| 赛后纪念物 | **Supplies** 中的纪念物记录，属于不可穿物品。 |

:::

蓝叶森林的三件夜谈赠礼按 [装备页的连续三晚步骤](equipment.md#blueleaf-gifts)取得；装备取得与新增可切换外观之间没有逐件对应关系。背包地图（Map）的持有／挂带与地区地图列表也是不同的记录。[帮助速查](../help.md#help-state-table)。

<a id="dressing-room-recovery"></a>

## 补收集与旧档 {#列表缺项时按这个顺序核对}

表情可从场景前的普通存档重看；可选衣物从奖励、购买或分支窗口前补收；自动外观随对应剧情节点开放。Trailmarker 用于返回剧情位置，观看与换装记录仍依据实际呈现和取得。

旧存档与换设备后的列表可能随保留下来的观看和外观记录而有差异。存档与迁移说明见[回归帮助](../help.md#help-trailmarkers)。
